# 2026-09-30 · 01 · Pilot: MQAR at r ∈ {0, 1/2, 1} (abandoned: attention baseline did not learn)

Sweep: `configs/sweeps/pilot_mqar.yaml` (tag `pilot_mqar`). Code at commit e9194b0.

## Hypothesis

Written before any result. At d = 64 and L = 128, pure attention solves MQAR up to 24 to 32 pairs; pure Mamba-2 and pure Gated DeltaNet degrade as P grows because their per-layer state (1,152 and 512 entries at d = 64) has to hold P bindings; r = 1/2 is close to r = 1.

## Reason for running

Stage 4 gate: confirm the probe separates architectures at CPU-affordable scale and find the difficulty range worth sweeping.

## Configuration

d = 64, 8 layers, ~0.35M parameters (matched within 3%), L = 128, train on P ∈ {4, 8, 16, 24} round-robin, evaluate P ∈ {4, 8, 16, 24, 32} (32 is out of distribution), 3,000 steps × 32 sequences, LR ∈ {1e-3, 3e-3}, seed 0. 2 workers × 2 CPU threads.

## Expected result

- r = 1: > 0.9 token accuracy at P ≤ 24.
- r = 0: accuracy falling with P; Gated DeltaNet above Mamba-2 at equal P (delta rule can overwrite; Mamba-2 only decays), despite GDN's smaller state.
- r = 1/2: within 0.05 of r = 1.
- If r = 0 is at ceiling for all P, the task is too easy at this length and needs larger P or L.

## Observed result (MEASURED, validation split, pure attention only)

The first launch was killed by a container restart at step 1,500 and discarded. The relaunch ran
attention-only configs first. Neither left the 1/P plateau:

| run | step | loss | val token acc, P = 4 / 8 / 16 / 24 / 32 |
|---|---|---|---|
| attn, lr 1e-3 | 1,500 | 3.05 | 0.26 / 0.16 / 0.09 / 0.07 / 0.05 |
| attn, lr 3e-3 | 2,000 | 2.79 | 0.26 / 0.15 / 0.10 / 0.07 / 0.06 |

Partial run directories kept in `artifacts/abandoned/`. No recurrent run was started.

## Interpretation

The model learned which values occur in context but not the key-value binding. A separate sanity check
(entry 02) shows the attention implementation leaves this plateau quickly on an easier setting, so the
pilot configuration was too hard for its step budget at this scale.

## Potential confounds

- One seed; LR grid of two values.
- Recurrent state differs by family (1,152 vs 512).
- 3,000 steps may be short for recurrent models on MQAR.

## Decision

Stopped the pilot at step 2,000 of the attention-only runs to avoid spending CPU on recurrent runs that
could not be compared against a working attention baseline.
